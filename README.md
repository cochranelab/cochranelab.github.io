# Cochrane Lab website — v1

A from-scratch static replacement for the previous AcademicPages/Jekyll personal site.

## Preview locally
Open `index.html` in a browser, or run a simple local web server from this folder.

## Deploy to GitHub Pages
Replace the contents of the existing `ryanrcochrane.github.io` repository with these files and push to the default publishing branch. Because this is plain HTML/CSS, GitHub Pages can serve it directly.

## Before publishing
- Verify/update publication metadata and add DOI links.
- Add ORCID, Google Scholar, LinkedIn and institutional profile links.
- Replace the legacy portrait if desired.
- Add team members as the group grows.
- Consider a custom domain once the lab name/brand is final.
